# TaskFlow — Task Management App

TaskFlow is a lightweight personal task manager built with plain HTML, CSS, and JavaScript. It helps you organize everyday work, see what needs attention, and keep your progress available in the browser.

## Features

- Create tasks with a title, description, category, priority, and due date.
- Edit task details and mark tasks as complete or pending.
- Delete tasks with a confirmation prompt.
- Filter the list by status (all, pending, or completed) and priority.
- View total, completed, and pending task counts at a glance.
- Save tasks in `localStorage` so they remain available after closing or refreshing the page.
- Use a responsive interface with keyboard-friendly controls and reduced-motion support.

## Technologies

- HTML5 for semantic structure and accessible form controls.
- CSS3 for layout, responsive styling, and subtle animations.
- Vanilla JavaScript for DOM updates, events, validation, and local storage.

No package installation or build step is required.

## Run locally

1. Download or clone this project.
2. Open `index.html` in a modern browser.
3. Add a task to get started. Your tasks are saved in that browser's local storage.
